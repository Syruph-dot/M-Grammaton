# M-Grammaton 概念设计

## 一、项目名称含义

**M-Grammaton**：
- **M** = Memory / Multi-agent / Meta（记忆 / 多智能体 / 元认知）
- **Grammaton** = 源自希腊语 γράμμα (gramma)，意为"书写、文字、知识创造"

合意为：**一个能够书写、组织、并自我演化知识的记忆系统**——不仅是知识的存储，更是知识的**创造与编排**。

---

## 二、核心愿景

构建一个**自组织知识图谱系统**，其中：

1. 知识以**加权有向图**的形式存在，节点和边的权重随交互动态演化
2. 多个具有**不同人格/认知偏好**的 Operator（操作者/智能体）在图上并行活动
3. 通过**问答循环 + 二元反馈**驱动图的权重自组织，形成涌现性的知识结构
4. 模拟生物记忆的关键特性：**遗忘、压缩、强化、联想**

最终目标是探索一种**非梯度下降、非向量嵌入**的知识表示与学习方法——基于图的动力学和集体交互来实现智能。

---

## 五、核心机制详解

### 5.1 记忆图 (`mg`)

图是系统的**唯一数据模型**。没有关系型表，没有向量数据库——一切皆为节点与边。

- **节点**：携带内容 (`content`)、种类 (`kind`)、标签、父子关系（树结构用于组织）以及时间属性
- **边**：加权有向，权重 ∈ [0, 1]，代表关联强度/转移概率
- **双重结构**：节点同时存在于**树**（`parent`/`children`，用于文件系统式组织）和**图**（`outlinks`/`inlinks`，用于语义关联）中
- **时间属性**：`t_read`, `t_write`, `t_lp` 记录访问历史，`t_lp` 采用指数移动平均，偏向近期

### 5.2 学习规则：`polar_redist`

这是系统的**核心创新**——取代梯度下降的学习机制：

1. Operator 在图上随机游走，对所经过的边给出 **正向/负向** 二元反馈
2. 反馈以 `binResponse(reaction, edge)` 形式压入边的源节点的 `stk`（栈）
3. 当连续两次反馈的符号**不同**时，触发 `polar_redist`：
   - 将（正权重, 负权重）视为极坐标中的向量
   - 将角度 θ 折半（atan2 → θ/2）
   - 按原幅值和新角度重新投影
   - 效果：**将权重从负反馈边转移到正反馈边**，幅值守恒
4. 栈底腐烂机制（beta）
   - 如果一个栈过长（我们知道这个栈的response都是一样的），底下的，时间过于久远，那么可以视为没有足够证据应该使它收到影响，甚至可能会作为一种没有时效性的信息，应该使其无效化。这是采用类栈结构的一个原因，当然此时stk严格意义上是队列。
   - 系统每过1分钟统计所有栈内元素总数，如果元素总数大于节点个数，（按长度引入随机扰动）分配每个栈需要腐烂的个数，目标总共需要腐烂的数量为floor(数量*0.15)。

```
polar_redist(+0.8, -0.3):
  θ = atan2(0.3, 0.8) ≈ 0.359
  θ' = 0.179
  amp = sqrt(0.64 + 0.09) ≈ 0.854
  new_positive = 0.854 × cos(0.179) ≈ 0.841
  new_negative = 0.854 × sin(0.179) ≈ 0.152
```

这种设计模拟了**赫布学习**（Hebbian learning）的广义形式——共同激活的加强连接，但不依赖数值梯度。

### 5.3 Operator（操作者）

Operator 是系统中**唯一的行为主体**。每个 Operator 拥有：
- **身份** (`id`)：唯一标识
- **人格**：通过 MBTI 类型定义（从 `01-最终送入设计.md` 可知，系统提示词包含 MBTI）
- **当前节点** (`current`)：Operator 在记忆图中的"注意力焦点"，通过 `NodePtr` 弱引用
- **已提交任务** (`submitted_quests`)：该 Operator 发起的提问历史

Operator 的核心行为：
| 行为 | 方法 | 描述 |
|------|------|------|
| 漫游 | `random_act` | 沿 L2 加权边随机游走，给出随机二元反馈 |
| 提问 | `ask` | 在图/板上创建 QuestNode，自动关闭旧任务 |
| 寻找任务 | `find_quest` | 从 QuestBoard 获取可回答的任务（排除自己的） |
| 导航 | `navigate_to` | 通过有偏游走向目标节点移动，失败时建立弱连接 |
| 回答 | `answer_quest` | 导航到任务节点 + 提交答案 |
| 评分 | `score_answer` | 对答案评分，更新回答者→提问者的边权重 |

### 5.4 QuestBoard（任务板）

管理**提问-回答**的生命周期：

```
提问 (ask) → 加入 active[]
回答 (answer) → 记录 answers[], from_ids[], scores[]
评分 (score) → 更新 scores[i]
关闭 (close) → 从 active 移到 completed
```

排序机制 (`available_for`)：按节点的三种时间属性之一排序，随机选择升序/降序——引入**受控随机性**以避免僵化。

### 5.5 上下文管理

从 `01-最终送入设计.md` 揭示的提示词架构：

- **历史链**：多块链式上下文，每块有 75% 概率将正文替换为摘要（压缩），3% 概率被删除并替换为"已忘记"（遗忘）
- **收藏**：跨会话的高价值节点引用，抵抗遗忘
- **分支提示词**：
  - 分支1（内容部）：提供材料（出题模式）或 questnode 内容（回答模式）
  - 分支2（任务部）：提供出题提示词或回答提示词

这一层尚未在 Python 代码中实现——是目前唯一的纯设计描述。

### 5.6 标签系统（`Tag`）

原型阶段，定义了：
- 标签到节点的 `outlinks`
- 标签到标签的 `conc_tags`（概念关联，带权重）
- 标签的 `aliases`（同义词/别名）

目标是一个**轻量级本体层**，不依赖预定义分类体系，而是从交互中涌现。

## 六、当前应用层：阅读理解命题与回答

系统选择的**验证场景**是**文学阅读理解**（以东方 Project 文本为素材），原因推测：

1. **高歧义性**：文学分析没有标准答案，天然适合多视角讨论
2. **丰富的可解释性**：答案质量可通过"匹配度"和"新颖度"多维度评估
3. **创造性要求**：最后一道题必须是开放题，测试系统的生成能力
4. **命题元认知**：系统不仅要回答问题，还要**学会出好问题**——这是更高阶的智能

当前流程：
```
材料 → Operator(A) 命题 → QuestNode入图
     → Operator(B,C,D) 回答 → 边权重更新
     → Operator(A) 评分 → 回答者↔提问者边权重更新
     → 归一化 → 下一轮
```

基于代码中的"占位"和设计文档的暗示：

1. **上下文管理器 (`ContextManager`)**：代码中 `01-最终送入设计.md` 详细描述了上下文链的遗忘/压缩机制，但 Python 侧完全未实现
2. **MBTI 人格层**：设计文档提到 Operator 应有 MBTI，当前代码中的 Operator 是无个性的
3. **收藏系统**：设计文档提到"收藏"分支，当前无实现
4. **多会话持久化**：图状态仅在内存中，无序列化/持久化机制
5. **标签-本体集成**：`Tag` 类已定义但未与 `mg` 图或 Operator 行为集成
6. **真正的 LLM 集成**：当前 Operator 的行为是随机/规则驱动的（`randint`, 预设评分策略），`01-最终送入设计.md` 描述的是 LLM 调用的提示词架构——暗示每个 Operator 背后应该是一个 LLM 调用
7. **多轮对话/讨论**：当前 `run_quest_demo.py` 是一轮提问+全部回答+全部评分，但架构允许多轮嵌套讨论
8. **图的涌现属性**：`test_random_walk.py` 的可视化暗示了一种观察——长期随机游走+反馈后，图的权重结构是否会涌现出有意义的聚类或路径

## 八、技术哲学

M-Grammaton 体现了几项非正统的技术立场：

1. **图原生 (Graph-Native)**：不是"向量数据库+图增强"，而是以图为第一性表示。权重即概率，结构即记忆。

2. **交互即学习 (Interaction as Learning)**：不需要离线训练/在线推理的分界。每次游走、每个评分、每条反馈都直接修改图。学习与使用是同一过程。

3. **多主体共构 (Multi-Agent Co-Construction)**：知识不是单一模型的内化，而是多个视角（Operator）在共享图上碰撞、协商、留下痕迹的涌现结果。

4. **生物启发 (Bio-Inspired)**：遗忘不是 bug 而是 feature；压缩是对记忆成本的模拟；`polar_redist` 的幅值守恒暗示了某种零和资源重分配。

5. **反黑箱 (Anti-Blackbox)**：图的所有状态都是可检查、可解释的——你可以随时查看节点间的边权重变化，追踪影响力的流动。
